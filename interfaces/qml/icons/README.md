# Material Icons

These SVGs are from Google's Material Design Icons repository:
https://github.com/google/material-design-icons

They use the Apache License 2.0; see LICENSE in this directory.
The preview uses edit (outlined), delete_outline, drag_handle, refresh,
public, visibility and visibility_off, matching the Material icon family
used by Flet. Qt tints the local SVGs with the shared theme colors.
